## Run

Node.js 20 or later. No installation or build required.

```sh
npm run dev
```

Open http://127.0.0.1:4173. Run `npm run check` for JavaScript syntax checks. Deploy the repository root to Vercel as an Other/static project; `vercel.json` supplies configuration.

## Interaction

Hover, keyboard-focus or tap a shape to select an app and change the whole atmosphere. The Open app and Source code links always remain directly available. Selection produces a spray of contextual particles and an elliptical ripple. CSS sculptures tilt with the pointer; local Three.js geometry floats in depth and responds to pointer, selection and scrolling. All text and links work if WebGL or JavaScript is unavailable. The Motion switch and system reduced-motion setting stop animation; rendering also pauses in background tabs.
